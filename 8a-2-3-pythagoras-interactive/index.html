① 畢氏定理

課本 P.95–98 · 探索活動、商高定理與《周髀算經》

定義

直角三角形中，直角所對的邊稱為斜邊，另外兩邊稱為股。

公式／性質

∠C = 90° ⟹ a² + b² = c²
即 BC² + CA² = AB²

重要提醒
  • 證明：4 個全等直角三角形加一個小正方形，拼成邊長 c 的大正方形，c² = 4×½ab + (b−a)² = a²+b²。
  • 中國稱為商高定理（勾股定理）：「勾廣三，股修四，徑隅五」。
例

兩股長 5 和 12，斜邊 = √(5²+12²) = 13。
弦圖：3×4×2 + (4−3)² = 5²。

互動：三個正方形的面積

教學提示：先回到溫故啟思：方格紙上甲 = 8，乙＋丙 = 8。再用 1, 1 的預設看斜邊平方 = 2。拼圖證明可以請學生用四個全等直角三角形實際拼拼看。

② 利用畢氏定理求長度

課本 P.99、P.102 · 例 1、「斜邊是哪一邊？」

定義

已知直角三角形的兩邊，可以用畢氏定理求第三邊。長度為正，所以平方後開根號要取正值。

公式／性質

斜邊² = 股² + 股²
一股² = 斜邊² − 另一股²

重要提醒
  • 先找出斜邊（直角所對的邊），再列式。
  • 3、4、x 的三角形，x 不一定是斜邊。
  • 矩形、正方形的對角線可切出直角三角形。
例

AB=6，BC=8，AC² = 36+64 = 100，AC = 10。
EG=10，EF=7，FG² = 100−49 = 51，FG = √51。

互動：求第三邊

教學提示：依霖的錯誤：把 4²+3²=x² 當成 x 是斜邊，但圖中 4 才是直角對面的斜邊，正確是 3²+x²=4²，x=√7。要求學生每題先圈出斜邊。

③ 正三角形與斜邊上的高

課本 P.100–101 · 例 2、例 3

定義

等腰三角形（含正三角形）是線對稱圖形，底邊上的高會平分底邊，形成兩個直角三角形。

公式／性質

正三角形邊長 a：
高 = (√3/2)a，面積 = (√3/4)a²
斜邊上的高：½×股×股 = ½×斜邊×高

重要提醒
  • 高 AD = √(AB² − BD²)，BD 是底邊的一半。
  • 斜邊上的高用「面積算兩次」求出。
例

AB=AC=10，BC=12：高 = √(100−36) = 8，面積 = 48。
兩股 10、24：BC = 26，AD = 120/13。

互動：三種三角形的高

教學提示：正三角形高的公式可以讓學生自己用邊長 a 推導，再背熟 √3/2 與 √3/4。斜邊上高的面積法：兩種方式算同一個三角形面積。

④ 數線上的 √a 與畢氏螺線

課本 P.102–103 · 例 4

定義

在直角三角形上不斷以前一條斜邊為一股、另一股取固定長，就能依序畫出 √2、√3、√4⋯⋯，形成畢氏螺線。

公式／性質

OB² = 2² + 1² = 5 ⟹ OB = √5
OC² = (√5)² + 1² = 6 ⟹ OC = √6

重要提醒
  • 以 O 為圓心、OC 為半徑畫弧，交數線於一點，該點坐標就是 √6（左邊則為 −√6）。
  • 調整兩股長，可以畫出特定的方根。
例

OA=AB=BC=CD=3：
OB=3√2，OC=3√3，OD=6，E 點坐標為 6。

互動：畢氏螺線

教學提示：課本附錄二與附件 7 可以摺出畢氏螺線。可讓學生把 L 調成 3，N 調成 4，對照隨堂練習的答案 OB=3√2、OC=3√3、OD=6。

⑤ 畢氏定理的生活應用

課本 P.104–105 · 例 5、例 6

定義

螢幕尺寸是對角線長度，長寬比設為 10r : 7r，用畢氏定理解出 r。梯子、竹竿靠牆也形成直角三角形。

公式／性質

(10r)² + (7r)² = 11²
梯長² = 梯腳到牆² + 梯頂高度²

重要提醒
  • 設比例的係數 r，r 為正數。
  • 計算機可求近似值：110√149/149 ≒ 9.01 吋。
例

梯長 250，梯腳離樹 150，梯頂高 200；
往前移 80 後，梯腳離樹 70，梯頂高 240。

互動：梯子靠牆

互動：螢幕長寬

教學提示：把比例設成 4:3、對角線 20，會得到整數 16 與 12（課本隨堂練習）。10:7 的比例則需要化簡根式，正好複習有理化分母。

⑥ 距離公式

課本 P.106–109 · 例 7、例 8

定義

坐標平面上兩點 A(x₁, y₁)、B(x₂, y₂)，過 A 作水平線、過 B 作鉛垂線交於 C(x₂, y₁)，△ABC 為直角三角形。

公式／性質

AB = √[(x₂−x₁)² + (y₂−y₁)²]
同一水平線：AB = |x₂−x₁|
同一鉛垂線：CD = |y₂−y₁|

重要提醒
  • x 坐標的差、y 坐標的差，先平方再相加。
  • 地圖要乘上比例尺，例如每格 100 公尺。
例

A(2,3)、B(5,7)：AB = √(3²+4²) = 5。
C(−3,7)、D(3,5)：CD = √40，約 632 公尺。

互動：任意兩點的距離

教學提示：讓學生調出 A 與 B 同 y 值，驗證公式退化為 |x₂−x₁|。例 8 周長題：A(4,−2)、B(2,4)、C(−3,−1)，周長 = 2√10 + 10√2。

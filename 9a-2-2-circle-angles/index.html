① 圓心角與弧的關係

課本 P.110–111 · 例 1 · 學習內容 S-9-6

定義

圓上一弧的度數就是其所對圓心角的度數。把圓周分成 360 等分，每一等分所對的圓心角是 1°。

公式／性質

∠AOB = x° ⟹ 弧 AB = x°
弧 AB 的長度 = 圓周長 × x/360

重要提醒
  • 同圓或等圓中，度數相同的兩弧，弧長相等。
  • 弧的符號有三種意義：圖形、度數、長度，要看前後文分辨。
  • 半徑不同的兩圓，相同圓心角所對弧的度數相等，弧長不相等。
例

同心圓半徑 8、10，圓心角 120°：
弧 AB 長 = 2π×8×120/360 = 16π/3
弧 CD 長 = 2π×10×120/360 = 20π/3

互動：兩個同心圓，同一個圓心角

教學提示：先問學生「看到弧的符號時，你怎麼知道它是在說度數還是長度？」再看例 1：度數相同、長度不同。課本海盜船情境的答案：角度一樣，因為船首與中間所夾的圓心角固定。

② 等弧對等弦

課本 P.112–113 · 例 2、例 3

定義

同圓或等圓中，度數相等的兩弧稱為等弧，長度相等的兩弦稱為等弦。

公式／性質

弧 AB = 弧 CD ⟺ 弦 AB = 弦 CD
證明：△AOB ≅ △COD（SAS 或 SSS）

重要提醒
  • 等弧對等弦、等弦對等弧，兩個方向都成立。
  • 正 n 邊形的頂點在圓上時，各邊所對的弧相等。
例

正五邊形 ABCDE 頂點在圓 O 上：
弧 ABC = 360°×2/5 = 144°，所以 ∠AOC = 144°。

互動：比較弧與弦

教學提示：讓學生把 CD 的度數調到 280° 左右，會看到弧比較大但弦比較短。課本結論只說「相等」，不說「較大」，因為弦長與弧的大小在超過 180° 後不再同向。

③ 圓周角與半圓的圓周角

課本 P.114–119 · 例 4、例 5、例 6

定義

兩弦的交點在圓周上，所形成的角稱為圓周角。∠BAC 所對的弧是弧 BC。

公式／性質

圓周角 = 所對弧度數 ÷ 2 = 圓心角 ÷ 2
同弧所對的圓周角相等
半圓所對的圓周角 = 90°

重要提醒
  • 圓心可能在圓周角的一邊上、內部、外部，結論都一樣。
  • 圓周角 ∠ADC 所對的弧可能是優弧：∠ADC = ½(360°−弧 ADC)。
例

∠AOC = 130°，則 ∠ABC = 65°（B 在優弧上）；
同一條弧另一側的 ∠ADC = ½×230° = 115°。

互動：拖動頂點 A，看圓周角怎麼變

教學提示：把弧 BC 調成 180°，圓心在一邊上，∠BAC = 90°。再慢慢縮小，圓心進入角內；拖動 A 位置讓圓心跑到角外。課本三種情形：圓心在一邊上、在內部、在外部。小翊的說法「同弧所對圓周角相等」正確；小妍的說法錯在 ∠AEB = ∠CED（對頂角）不能推出 AB = CD。

④ 平行弦截等弧

課本 P.120 · 例 7

定義

圓內兩條互相平行的弦 AB、CD，它們之間夾出兩段弧：弧 AC 與弧 BD。

公式／性質

AB ∥ CD ⟹ 弧 AC = 弧 BD
弧 AC = 弧 BD ⟹ AB ∥ CD

重要提醒
  • 證法：連接 BC，由內錯角 ∠1=∠2，得 ½弧AC = ½弧BD。
  • 反過來也成立：連接 AD，內錯角相等就平行。
例

弧 AC = 弧 BD，∠DAB = 37°，則 ∠ADC = 37°，AB ∥ CD。

互動：轉動、平移兩條平行弦

教學提示：學生常以為要用全等三角形證明。這裡的關鍵是「連一條線，把兩段弧變成兩個圓周角」，再用內錯角相等。

⑤ 圓內接四邊形

課本 P.121–122 · 例 8

定義

四邊形的四個頂點都在圓周上，稱為圓內接四邊形。

公式／性質

∠A + ∠C = 180°，∠B + ∠D = 180°
外角 = 內對角：∠1 = ∠BAD

重要提醒
  • 證明：∠A = ½弧BCD、∠C = ½弧BAD，相加 = ½×360° = 180°。
  • 延長一邊得到的外角，等於它的內對角。
例

∠ABC = 70°，∠BAD = 115°：
∠ADC = 180°−70° = 110°，∠DCE = ∠BAD = 115°。

互動：移動四個頂點

教學提示：讓學生拖到任何位置，兩組對角和都停在 180°。再用「弧BCD + 弧BAD = 360°」說明為什麼。教學指引提到圓外一點作切線，其實是用「半圓的圓周角是直角」，不是教學重點，讓學生知道尺規真的畫得出來即可。

⑥ 素養：內輪差

課本 P.126 · 扉選素養（SDGs 3 良好健康和福祉）

情境

大型車輛轉彎時，前內輪與後內輪的旋轉半徑之差稱為內輪差，紅色區域是危險區域，行人要保持更遠的距離。

公式／性質

內輪差 = OA − OB
危險區面積 = △AOB − 扇形 OBC

重要提醒
  • ∠OBA = 90°，∠AOB = 轉彎角度 θ。
  • OB = AB / tanθ，OA = AB / sinθ。
例

AB = 4，θ = 30°：OA = 8，OB = 4√3
內輪差 = 8 − 4√3 公尺
面積 = 8√3 − 4π 平方公尺

互動：車長與轉彎角度如何影響危險區

教學提示：課本建議討論「為什麼車越長或轉彎角度越大，內輪差就會越大？」拖動兩個滑桿讓學生觀察。可連結交通安全，培養對公共安全的責任感。

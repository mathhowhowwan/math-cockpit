① 圓心角與弧的關係

課本 P.110–111 · 例 1 · 學習內容 S-9-6

定義

圓上一弧的度數就是其所對圓心角的度數。把圓周分成 360 等分，每一等分所對的圓心角是 $1^\circ$。

公式／性質

$\angle AOB = x^\circ \;\Rightarrow\; \arc{AB} = x^\circ$
$\arc{AB}$ 的長度 $=$ 圓周長 $\times \dfrac{x}{360}$

重要提醒
  • 同圓或等圓中，度數相同的兩弧，弧長相等。
  • 弧的符號有三種意義：圖形、度數、長度，要看前後文分辨。
  • 半徑不同的兩圓，相同圓心角所對弧的度數相等，弧長不相等。
例

同心圓半徑 8、10，圓心角 $120^\circ$：
$\arc{AB}$ 長 $= 2\pi\times 8\times\dfrac{120}{360} = \dfrac{16\pi}{3}$
$\arc{CD}$ 長 $= 2\pi\times 10\times\dfrac{120}{360} = \dfrac{20\pi}{3}$

互動：兩個同心圓，同一個圓心角

教學提示：先問學生「看到弧的符號時，你怎麼知道它是在說度數還是長度？」再看例 1：度數相同、長度不同。課本海盜船情境的答案：角度一樣，因為船首與中間所夾的圓心角固定。

② 等弧對等弦

課本 P.112–113 · 例 2、例 3

定義

同圓或等圓中，度數相等的兩弧稱為等弧，長度相等的兩弦稱為等弦。

公式／性質

$\arc{AB} = \arc{CD} \iff \overline{AB} = \overline{CD}$
證明：$\triangle AOB \cong \triangle COD$（SAS 或 SSS）

重要提醒
  • 等弧對等弦、等弦對等弧，兩個方向都成立。
  • 「等弦對等弧」指的是同為劣弧的兩弧；同一條弦所對的優弧與劣弧，度數並不相等。
  • 正 $n$ 邊形的頂點在圓上時，各邊所對的弧相等。
例

正五邊形 $ABCDE$ 頂點在圓 $O$ 上：
$\arc{ABC} = 360^\circ\times\dfrac{2}{5} = 144^\circ$，所以 $\angle AOC = 144^\circ$。

互動：比較弧與弦

教學提示：讓學生把弧 CD 調到 $300^\circ$ 左右，會看到弧比較大但弦比較短；再把弧 AB 設 $80^\circ$、弧 CD 設 $280^\circ$，兩弦竟然相等，因為這是劣弧與優弧的組合（$80^\circ+280^\circ=360^\circ$）。所以課本結論只說同為劣弧的等弧與等弦互相對應，不說「弧大弦就長」。

③ 圓周角與半圓的圓周角

課本 P.114–119 · 例 4、例 5、例 6

定義

兩弦的交點在圓周上，所形成的角稱為圓周角。$\angle BAC$ 所對的弧是 $\arc{BC}$。

公式／性質

圓周角 $=\dfrac{1}{2}\times$ 所對弧的度數 $=\dfrac{1}{2}\times$ 圓心角
同弧所對的圓周角相等
半圓所對的圓周角 $=90^\circ$

重要提醒
  • 圓心可能在圓周角的一邊上、內部、外部，結論都一樣。
  • 圓周角 $\angle ADC$ 所對的弧可能是優弧：$\angle ADC = \dfrac12(360^\circ-\arc{ADC})$。
例

$\angle AOC = 130^\circ$，則 $\angle ABC = 65^\circ$（$B$ 在優弧上）；
同一條弧另一側的 $\angle ADC = \dfrac12\times 230^\circ = 115^\circ$。

互動：拖動頂點 A，看圓周角怎麼變

教學提示：把弧 $BC$ 調成 $180^\circ$，$BC$ 就是直徑，無論 $A$ 在哪裡，$\angle BAC$ 都是 $90^\circ$（半圓的圓周角）。再慢慢拖動 $A$：當 $AB$ 或 $AC$ 剛好通過圓心 $O$ 時就是「圓心在一邊上」，其他位置則是圓心在角的內部或外部，課本三種情形都能看到。小翊的說法「同弧所對圓周角相等」正確；小妍的說法錯在 $\angle AEB=\angle CED$（對頂角）不能推出 $AB=CD$。

④ 平行弦截等弧

課本 P.120 · 例 7

定義

圓內兩條互相平行的弦 $AB$、$CD$，它們之間夾出兩段弧：$\arc{AC}$ 與 $\arc{BD}$。

公式／性質

$AB \parallel CD \;\Rightarrow\; \arc{AC} = \arc{BD}$
$\arc{AC} = \arc{BD} \;\Rightarrow\; AB \parallel CD$

重要提醒
  • 證法：連接 $BC$，由內錯角 $\angle 1=\angle 2$，得 $\dfrac12\arc{AC}=\dfrac12\arc{BD}$。
  • 反過來也成立：連接 $AD$，內錯角相等就平行。
例

$\arc{AC}=\arc{BD}$，$\angle DAB = 37^\circ$，則 $\angle ADC = 37^\circ$，$AB \parallel CD$。

互動：轉動、平移兩條平行弦

兩個「位置」滑桿的數字，就是弦的端點離開直徑的角度，所以兩弦之間的弧度數可以直接算出來。

教學提示：學生常以為要用全等三角形證明。這裡的關鍵是「連一條線，把兩段弧變成兩個圓周角」，再用內錯角相等。

⑤ 圓內接四邊形

課本 P.121–122 · 例 8

定義

四邊形的四個頂點都在圓周上，稱為圓內接四邊形。

公式／性質

$\angle A + \angle C = 180^\circ$，$\angle B + \angle D = 180^\circ$
外角 $=$ 內對角：$\angle 1 = \angle BAD$

重要提醒
  • 證明：$\angle A=\dfrac12\arc{BCD}$、$\angle C=\dfrac12\arc{BAD}$，相加 $=\dfrac12\times 360^\circ=180^\circ$。
  • 延長一邊得到的外角，等於它的內對角。
例

$\angle ABC = 70^\circ$，$\angle BAD = 115^\circ$：
$\angle ADC = 180^\circ-70^\circ=110^\circ$，$\angle DCE = \angle BAD = 115^\circ$。

互動：移動四個頂點

四個滑桿控制四個頂點在圓上的位置；頂點依逆時針順序標為 A、B、C、D。

教學提示：讓學生拖到任何位置，兩組對角和都停在 $180^\circ$。再用 $\arc{BCD}+\arc{BAD}=360^\circ$ 說明為什麼。教學指引提到圓外一點作切線，其實是用「半圓的圓周角是直角」，不是教學重點，讓學生知道尺規真的畫得出來即可。

⑥ 素養：內輪差

課本 P.126 · 扉選素養（SDGs 3 良好健康和福祉）

情境

大型車輛轉彎時，前內輪與後內輪的旋轉半徑之差稱為內輪差，紅色區域是危險區域，行人要保持更遠的距離。

公式／性質

內輪差 $=OA-OB$
危險區面積 $=\triangle AOB-$ 扇形 $OBC$

重要提醒
  • $\angle OBA=90^\circ$，$\angle AOB=$ 轉彎角度 $\theta$。
  • $OB=\dfrac{AB}{\tan\theta}$，$OA=\dfrac{AB}{\sin\theta}$。
例

$AB = 4$，$\theta = 30^\circ$：$OA = 8$，$OB = 4\sqrt{3}$
內輪差 $= 8-4\sqrt{3}$ 公尺
面積 $= 8\sqrt{3}-4\pi$ 平方公尺

互動：車長與轉彎角度如何影響危險區

教學提示：課本建議討論「為什麼車越長或轉彎角度越大，內輪差就會越大？」拖動兩個滑桿讓學生觀察。轉彎角度剛好是 $30^\circ$、$45^\circ$、$60^\circ$ 時，頁面會用根號與 $\pi$ 顯示精確值。可連結交通安全，培養對公共安全的責任感。

總結 Cheat Sheet

課本 P.123 重點整理

圓心角

$\angle AOB = \arc{AB}$

圓周角

$\angle BAC = \dfrac12\arc{BC}$
$=\dfrac12\angle BOC$

半圓的圓周角

$\angle ACB = 90^\circ$
（$AB$ 為直徑）

平行弦的截弧

$AB \parallel CD \iff \arc{AC} = \arc{BD}$

圓內接四邊形

$\angle A+\angle C = 180^\circ$
$\angle B+\angle D = 180^\circ$

等弧等弦

$\arc{AB} = \arc{CD} \iff \overline{AB} = \overline{CD}$
（同為劣弧）

常見錯誤彙整：(1) 把圓周角當成圓心角（忘了除以 2）；(2) 圓周角所對的弧是優弧時，仍用劣弧計算；(3) 由 $\angle AEB=\angle CED$（對頂角）推出 $AB=CD$；(4) 半徑不同的圓，以為相同圓心角的弧長也相等；(5) 以為弧越大弦一定越長（超過 $180^\circ$ 就不成立）。

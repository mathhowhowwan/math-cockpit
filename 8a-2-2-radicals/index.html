認識根式

目標：辨認根號內外的數，理解根式簡記。｜課本 p.75–77

教學卡 1 / 3
定義 / 概念

含有根號的算式稱為根式；a√b 表示 a × √b，a 是係數，b 是被開方數。

公式 / 性質

a × √b = a√b；√b ÷ a = √b/a（a ≠ 0，b ≥ 0）

課本對照例

課本例 1：18√3 ÷ 6 = (18 ÷ 6)√3 = 3√3。

  • √9 = 3；9 的平方根才是 ±3。
  • 2 × 3√5 = 6√5，不能簡記成 23√5。

動手試一試

改變數值，觀察結果
3
教師教學提示

先用 2x + 3x 與 3x × (−5)x 喚醒係數概念，再將 x 換成 √3。區分根號值與平方根。

1. √36 的值為何？

2. 2 × 4√7 的簡記為何？

3. 15√2 ÷ 5 等於多少？

根式的乘除

目標：在正確條件下，運用根式乘除法則。｜課本 p.78–80

教學卡 1 / 3
定義 / 概念

乘除時，可分別處理係數與被開方數，最後再化簡。

公式 / 性質

√a × √b = √(ab)（a,b ≥ 0）；√a ÷ √b = √(a/b)（a ≥ 0，b > 0）

課本對照例

課本例 2：−2√3 × 3√7 = (−2 × 3)√21 = −6√21。

  • 除數不能為 0。
  • 根式乘法可以合進同一根號，加法卻不能照搬。

動手試一試

改變數值，觀察結果
教師教學提示

用面積 2 與 3 的兩塊正方形引出邊長 √2、√3，說明邊長相乘得到矩形面積 √6。

理解檢查 · 3 題

先想一想再選；送出後顯示解析，綠框標示正解。

1. √6 × √10 等於多少？

2. (−2√5)(3√2) 等於多少？

3. √48 ÷ √3 等於多少？

找出成對的因數

化為最簡根式

目標：將完全平方因數移出根號。｜課本 p.81–82

教學卡 1 / 3
定義 / 概念

把根式寫成 a√b，其中 b 為正整數，且不再含大於 1 的完全平方因數；若可化為有理數，就直接算出。

公式 / 性質

√(k²b) = k√b（k ≥ 0，b ≥ 0）；一般而言 √(x²) = |x|

課本對照例

課本例 4：√125 = √(25 × 5) = 5√5；√3 × √84 = √252 = 6√7。

  • 優先找最大的完全平方因數，例如 72 = 36 × 2。
  • 檢查根號內是否還有 4、9、16、25 等平方因數。

動手試一試

改變數值，觀察結果
72
教師教學提示

用面積 60 的正方形分割成 4 個面積 15 的小正方形，對應 √60 = 2√15。移出的是平方因數的平方根。

理解檢查 · 3 題

先想一想再選；送出後顯示解析，綠框標示正解。

1. √98 的最簡根式為何？

2. 以下哪個已是最簡根式？

3. √32 化簡時，移出根號的是哪個數？

分母有理化與近似值

目標：處理單項根式分母、分數與小數根式，最後才取近似值。｜課本 p.83–85

教學卡 1 / 3
定義 / 概念

有理化分母是把分母化成不帶根號的數，同時維持原式的值。

公式 / 性質

c/√b = c√b/b（b > 0）；√(p/q) = √(pq)/q（p ≥ 0，q > 0）

課本對照例

課本例 5：2/√3 = 2√3/3；√0.3 = √30/10；√(75/4) = 5√3/2。

  • 分子與分母必須同乘，不能只改分母。
  • 計算盡量保留精確根式，最後一步才取近似值。

動手試一試

改變數值，觀察結果
3
教師教學提示

用 √5 ≈ 2.236 示範 √500 = 10√5 ≈ 22.36。說明中途四捨五入可能累積誤差，避免宣稱每次近似必然使誤差單調增加。

1. 6/√3 化簡為何？

2. √0.5 化為最簡根式為何？

3. 已知 √2 ≈ 1.414，則 √200 約為多少？

05
先化簡，再合併

同類方根的加減

目標：判斷同類方根，只合併相同根號部分的係數。｜課本 p.85–87

教學卡 1 / 3
定義 / 概念

各項化為最簡根式後，根號部分相同，才能合併為同類方根。

公式 / 性質

a√b + c√b = (a + c)√b；√a + √b 一般不等於 √(a+b)

課本對照例

課本例 8：√27 + 5√12 = 3√3 + 10√3 = 13√3。

  • √8 與 √18 分別是 2√2、3√2，因此是同類方根。
  • 括號前有負號時，括號內每一項都要變號。

動手試一試

改變數值，觀察結果
教師教學提示

用不同顏色標記 √2 與 √3 兩種單位；先要求學生說出「能不能合併」的理由，再進行計算。

1. √20 + √45 等於多少？

2. 以下哪個與 √12 為同類方根？

3. √75 − (√12 + √27) 等於多少？

四則運算與乘法公式

目標：運用分配律、和差平方及平方差公式。｜課本 p.88–90

教學卡 1 / 3
定義 / 概念

根式四則運算遵守先括號、先乘除後加減；乘除同級由左至右。

公式 / 性質

(a+b)(a−b) = a²−b²；(a±b)² = a²±2ab+b²

課本對照例

課本例 11：(√5 + √3)(√5 − √3) = 2；(√11 − 3√2)² = 29 − 6√22。

  • (√a + √b)² 的中間項 2√(ab) 不能漏。
  • 平方差公式要先核對兩個括號的項與正負號。

動手試一試

改變數值，觀察結果

教師教學提示

用矩形面積把和的平方拆成四塊，讓學生看見兩塊 ab。再比較共軛相乘，中間項才會抵消。

理解檢查 · 3 題

先想一想再選；送出後顯示解析，綠框標示正解。

1. (√7 + √2)(√7 − √2) 等於多少？

2. (√3 + 2)² 等於多少？

3. √2(√8 + √18) 等於多少？

07
找到分母的共軛式

雙項分母的有理化

目標：利用平方差消除雙項分母的根號。｜課本 p.91–92

教學卡 1 / 3
定義 / 概念

將兩項式中間的加減號改變，得到共軛式；與原式相乘，可利用平方差。

公式 / 性質

1/(a+√b) = (a−√b)/(a²−b)（b ≥ 0，a² ≠ b）

課本對照例

課本例 12：1/(2 + √3) = (2 − √3)/(4 − 3) = 2 − √3。

  • 分子與分母都要乘上完整共軛式。
  • 分母若算出負數，應將負號整理進分子；分母不可為 0。

動手試一試

改變數值，觀察結果
教師教學提示

先讓學生預測分母會變成多少，再展開分子。對照 3/(√5 − √3)，提醒共軛式是 √5 + √3。

TAKEAWAYS

下課前，帶走這 6 句

① 乘除：係數、根號分開處理。

② 化簡：找完全平方因數。

③ 加減：先化簡，再合併同類。

④ 平方：不能漏掉中間項。

⑤ 有理化：分子分母同乘。

⑥ 近似值：盡量留到最後再取。

迷思診療：這三句哪裡錯？

√9 = ±3 → √9 = 3；9 的平方根才是 ±3。

√a + √b = √(a+b) → 一般不成立；例如 √9 + √16 = 7，而 √25 = 5。

(√a + √b)² = a+b → 漏了 2√(ab)，正確為 a+b+2√(ab)（a,b ≥ 0）。

① 因式、倍式與因式分解

課本 P.118–121 · 例 1

定義

若 A、B 都不為 0，且 A 可以被 B 整除（餘式為 0），稱 B 是 A 的因式，A 是 B 的倍式。把二次式寫成兩個一次式的乘積，稱為因式分解。

公式／性質

A = B × C ⟹ B、C 都是 A 的因式
A 是 B、C 的倍式
因式分解 ⇄ 展開

重要提醒
  • 用除法判別：餘式為 0 才是因式。
  • 餘式不為 0，B 就不是 A 的因式，A 也不是 B 的倍式。
例

(2x²+5x+2)÷(x+2) = 2x+1 餘 0，所以 2x²+5x+2 = (2x+1)(x+2)。
(2x²+5x+2)÷(x+3) = 2x−1 餘 5，不是因式。

互動：多項式除法判別器

被除式 A = ax² + bx + c，除式 B = px + q（p ≠ 0）

教學提示：例 1 的做法：已知一個一次因式，用除法求出另一個一次式，再比對 a、b。小練習 6x²−11x−7 = (3x−7)(2x+1)：3x−7 是因式、6x²−11x−7 是 3x−7 的倍式。學生常把「因式」和「倍式」說反，可用「小的是因式、大的是倍式」幫助記憶。

② 提公因式法（單項式）

課本 P.122–123 · 例 2

定義

當多項式的每一項都有公因式時，可以把公因式提出。x 是 x² 和 3x 的公因式。

公式／性質

A×B + A×C = A×(B + C)
x² + 3x = x(x + 3)

重要提醒
  • 係數的最大公因數和字母都要提乾淨，例如 4a+8a² = 4a(1+2a)。
  • x²+2x+3 不能因式分解：x(x+2)+3 是「乘積再加 3」，不是乘積。
例

x²−3x = x(x−3)
x(2x−4) − x(x+3) = x[(2x−4)−(x+3)] = x(x−7)

互動：x² + kx 的面積模型

互動：提出最大公因式

教學提示：浩南的錯誤：x²+2x+3 = x(x+2)+3。提公因式後如果後面還要「加上」一個數，就不是乘積，不算完成因式分解。

③ 提一次式公因式

課本 P.124–125 · 例 3、例 4

定義

各項裡出現相同的括號，例如 (x−2)，就把整個括號當成公因式提出來。

公式／性質

(x−5)(x−6) + (x+6)(x−5)
= (x−5)[(x−6)+(x+6)] = 2x(x−5)

重要提醒
  • 括號相反時先變號：(4−3x) = −(3x−4)。
  • 3x²−5x 和 6x−10 可分別提出 x 和 2，再得到公因式 (3x−5)。
  • 結果出現單項式時，通常放在最前面。
例

x(x−2)+(x−2) = (x−2)(x+1)
(3x−4)(3x+1)+(4−3x)(2x−1) = (3x−4)(x+2)

互動：提出一次式公因式

(px+q)(rx+s) ± (px+q)(tx+u)

教學提示：「例 4(1)」按鈕會把第二項的公因式變號並選擇 ＋，示範 (4−3x) = −(3x−4)。學生最容易在變號後忘記改括號中間的符號。

④ 利用平方差公式因式分解

課本 P.126–128 · 例 5、例 6

定義

型如 a² − b² 的多項式，可以因式分解成 (a+b)(a−b)。a、b 可以是數字、文字或整個括號。

公式／性質

a² − b² = (a + b)(a − b)
x² − 4 = x² − 2² = (x+2)(x−2)

重要提醒
  • 先提公因式，再看是否為平方差：3x²−12 = 3(x²−4) = 3(x+2)(x−2)。
  • c² − (px+q)² 展開括號後可能出現負號，要提出 −1。
  • x²＋100 不是平方差，不能因式分解。
例

4x²−9 = (2x)²−3² = (2x+3)(2x−3)
25−(x+7)² = −(x+12)(x+2)

互動：平方差的面積搬移

互動：平方差因式分解機

教學提示：小南的錯誤：4x²−1 寫成 (4x+1)(4x−1)，其實 4x² = (2x)²，正確是 (2x+1)(2x−1)。要求學生先把兩項都寫成平方的形式。

⑤ 利用和、差的平方公式因式分解

課本 P.129–131 · 例 7、例 8

定義

型如 a² ± 2ab + b² 的多項式，可以因式分解成 (a ± b)²。

公式／性質

a² + 2ab + b² = (a + b)²
a² − 2ab + b² = (a − b)²

重要提醒
  • 檢查：首尾兩項都是平方，中間項 = ±2×兩個底數的乘積。
  • 先提公因式：4x²−16x+16 = 4(x²−4x+4) = 4(x−2)²。
  • 中間項為正用和的平方，為負用差的平方。
例

x²+6x+9 = (x+3)²
36x²+60x+25 = (6x+5)²
18x²−24x+8 = 2(3x−2)²

互動：(x+k)² 的面積拆解

互動：是完全平方式嗎？

教學提示：「到底該用和的平方還是差的平方？」看中間項的正負號。學生常漏掉先提公因式這一步，例如 18x²−24x+8 直接看不出來，提出 2 之後才是 9x²−12x+4。

⑥ 綜合：選對方法

課本 P.132–134 · 重點整理、自我評量與挑錯題

做法順序
  • ① 有沒有公因式？先提出來。
  • ② 剩下的是兩項？看是否為平方差 a²−b²。
  • ③ 剩下的是三項？看是否為完全平方式 a²±2ab+b²。
公式／性質

a²−b² = (a+b)(a−b)
a²+2ab+b² = (a+b)²
a²−2ab+b² = (a−b)²

重要提醒
  • 不是每個多項式都能因式分解，例如 x²+100。
  • 做完用展開驗算。
例

2x²−32x+128 = 2(x²−16x+64) = 2(x−8)²

互動：因式分解判斷機

挑錯題答案（P.134）：小南：4x²−1 = (2x)²−1 = (2x+1)(2x−1)，他把 4x² 的底數寫成 4x，是錯的。小天：x²+100 不能因式分解，(x+10)(x+10) = x²+20x+100 ≠ x²+100。

總結 Cheat Sheet

課本 P.132 重點整理

因式與倍式

A = B×C
B、C 是 A 的因式

提公因式

AB + AC = A(B + C)

平方差

a²−b² = (a+b)(a−b)

和的平方

a²+2ab+b² = (a+b)²

差的平方

a²−2ab+b² = (a−b)²

做法順序

先提公因式 → 看兩項 → 看三項

常見錯誤彙整：(1) 因式與倍式說反；(2) 提公因式後還剩「＋常數」卻當作完成；(3) 括號相反時沒有變號；(4) 4x²−1 寫成 (4x+1)(4x−1)；(5) 把 x²+100 當成平方差或完全平方式；(6) 忘了先提公因式。

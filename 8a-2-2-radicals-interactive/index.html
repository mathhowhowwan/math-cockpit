① 根式的意義與簡記

課本 P.75–77 · 例 1

定義

含有根號（方根）的算式稱為根式，例如 2×√3、√3＋√2、(3/2)×√3 − 2×√2。

公式／性質

若 a≠0 且 b≥0：a×√b = a√b
√b ÷ a = √b / a = (1/a)√b

重要提醒
  • 根式運算規則與代數式相同，× 可以省略。
  • 4×(√2+√3) 簡記為 4(√2+√3)。
例

(−12)×5√3 = (−12×5)√3 = −60√3
18√3 ÷ 6 = 3√3

互動：正方形土地的邊長

兩塊正方形面積為 a、b，另外兩塊長方形面積各是多少？大正方形邊長是多少？

教學提示：先讓學生猜剩下兩塊土地的面積，再揭曉 √a×√b = √(ab)，自然銜接下一個重點。簡記時強調：係數與根號之間不寫×，但分數係數要放在根號前面。

② 根式的乘除運算

課本 P.78–81 · 例 2、例 3

定義

根號內的數可以直接相乘或相除：兩個非負數的方根相乘，等於它們乘積的方根。

公式／性質

a≥0, b≥0：√a × √b = √(a×b)
a≥0, b>0：√a ÷ √b = √a/√b = √(a/b) = √(a÷b)

重要提醒
  • 證明：(√a×√b)² = (√a)²×(√b)² = a×b。
  • 除法時 b 必須大於 0。
例

√5×√13 = √65
−2√3×3√7 = −6√21
√54 ÷ √9 = √6

互動：乘除驗算機

教學提示：用計算機比較 √3×√2 與 √6，讓學生看到小數相同；再比較 √2+√3 與 √5 製造衝突，下一個重點才會自然說明加減不能合併根號內的數。

③ 最簡根式

課本 P.81–82 · 例 4

定義

若根式可化簡為 a√b，其中 a 為整數、分數或小數，b 為正整數，且 b 的標準分解式中所有質因數的次方都是 1，稱 a√b 為最簡根式。

公式／性質

√60 = √(2²×15) = 2√15

重要提醒
  • 根號內不能有大於 1 的次方（平方因數）。
  • 根號內不能有小數、分數，分母也不能有根號。
例

√125 = √(5³) = 5√5
√3×√84 = √(2²×3²×7) = 6√7

互動：最簡根式化簡器

教學提示：引導學生先做質因數分解，再把「兩個一組」的質因數搬出根號。常見錯誤：只搬出一個平方就停止，例如 √300 寫成 √3×10²，忘了搬出 10。

④ 有理化分母

課本 P.83、P.91 · 例 5、例 12

定義

分母含根號時不是最簡根式，必須把分母化為不帶根號的數，這個過程稱為有理化分母。

公式／性質

c/√a：分子分母同乘 √a
c/(√a+√b)：同乘 (√a−√b)
c/(√a−√b)：同乘 (√a+√b)

重要提醒
  • 後兩種利用平方差公式：(√a+√b)(√a−√b)=a−b。
  • √0.3 與 √(75/4) 也要先化為分數再化簡。
例

2/√3 = 2√3/3
1/(2+√3) = 2−√3
√0.3 = √30/10

互動：有理化分母

教學提示：常見錯誤：1/√12 的最簡根式不是 1/(2√3)，而是 √3/6，因為分母仍有根號。分子分母同乘的數必須相同，才不會改變數值。

⑤ 同類方根的加減

課本 P.85–87 · 例 7、例 8

定義

化簡後根號內相同的根式（如 √2、3√2、−(3/5)√2）稱為同類方根。

公式／性質

2√2 + 3√2 = (2+3)√2 = 5√2

重要提醒
  • 加減前先把每一項化為最簡根式，再合併同類方根。
  • √2+√3 ≠ √(2+3)，不同類的方根不能合併。
例

√27 + 5√12 = 3√3 + 10√3 = 13√3
2√7 − 3√5 + 5√7 + 9√5 = 7√7 + 6√5

互動：先化簡，再合併

每一項為「係數 × √根號內的數」。係數填 0 表示不用這一項。

教學提示：用顏色標示同類方根（課本例 7 的做法）。常見錯誤：√8+√18 直接寫成 √26。要求學生先寫出 2√2＋3√2 這一步。

⑥ 根式的四則運算與乘法公式

課本 P.88–90 · 例 9、例 10、例 11

定義

四則運算：用分配律展開，把乘除化簡、同類方根合併，答案寫成最簡根式。

公式／性質

(a+b)(a−b) = a²−b²
(a±b)² = a² ± 2ab + b²
(√a)² = a

重要提醒
  • (√7+√5)(√5−√7) 要寫成 (√5)²−(√7)² = −2，不是 2。
  • 除以根式時，改乘倒數並有理化分母。
例

(√5+√3)(√5−√3) = 5−3 = 2
(√11−3√2)² = 29−6√22

互動：乘法公式驗算

教學提示：建宇的錯誤：(√7+√5)(√5−√7) 被誤當成 (√7+√5)(√7−√5)。請學生先找出「哪一項的平方放前面」：第一個括號的兩項與第二個括號的兩項，要看哪一項符號相同。

⑦ 根式的近似值

課本 P.84–85 · 例 6、數養知識

定義

每取一次近似值就產生一次誤差；取近似值的次數越多，結果與實際值差距越大。

公式／性質

√500 = 10√5 ≒ 10×2.236 = 22.36

重要提醒
  • 先化為最簡根式，再代入已知的近似值。
  • 要算 3√10/√6，建議先化簡再求近似值，誤差較小。
例

已知 √5≒2.236：
√45 = 3√5 ≒ 6.708

互動：誤差比一比（c√m ÷ √n）

教學提示：讓學生分組，一組先各自取近似再相除，一組先化簡，比較誰更接近計算機直接算出的值。

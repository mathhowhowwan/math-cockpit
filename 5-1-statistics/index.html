統計圖表的呈現與判讀

長條圖

呈現各類別次數。條形之間有間隔，資料不必按大小順序排列。例：各尺寸T恤件數。

折線圖

呈現資料隨時間的變化趨勢。連點成線，可看出上升、下降趨勢。例：PM₂.₅隨時間變化。

直方圖 vs 長條圖

長條圖：類別資料，條有間隔
直方圖：數值資料，條緊密相連

圓形圖 & 列聯表

圓形圖：呈現各項佔整體的百分比。列聯表：同時呈現兩種類別變數的次數分配。

重要提醒
  • 直方圖的每個長條底邊必須緊密相接
  • 圓形圖難以比較不同扇區大小，常被統計學家批評
  • 列聯表可呈現兩個屬性變數的不同類別
例

PM₂.₅排放源：工業16865、車輛16756、商業6440、營建27662、其他6132 公噸/年。
營建所佔百分比：27662÷73855×100%≈37%

🗝️ 教學提示

  • 引導學生區分長條圖與直方圖的差異：一個是類別資料，一個是數值資料且有大小順序
  • 圓形圖需用刻度為100等分的量角器，每個扇形的度數 = 百分比 × 3.6°
  • 列聯表Contingency Table：兩個屬性變數交叉呈現，可做百分比分析

📝 形成性評量

Q1. 七年甲班各種尺寸T恤的需求件數：S=4、M=14、L=7、XL=5。若要呈現各尺寸的件數，最適合用哪種統計圖？
✅ 正確！尺寸是類別資料（S/M/L/XL沒有連續大小關係），適合用長條圖。若想看各尺寸占總數的比例，才用圓形圖。
Q2. 下列敘述何者正確？
✅ 正確！列聯表（Contingency Table）將兩個屬性變數的不同類別置於行與列，呈現各組合的次數。A錯：直方圖長條緊密相接。B錯：折線圖呈現數值隨時間變化。D錯：長條圖不必按順序。
Q3. 某校調查學生接種疫苗意願：七年級願意140人、不願意20人；八年級願意162人、不願意38人。願意接種的學生占全體七八年級的百分比約為？
✅ 願意：140+162=302人，總計：(140+20)+(162+38)=360人，302÷360×100%≈83.9%≈83%。

統計資料的整理與分析

▶ 拖曳滑桿，調整各組次數，觀察直方圖與折線圖的變化
📋

次數分配表與直方圖

次數分配表

將資料按大小分組整理。步驟：① 找最大最小值 ② 決定組距（通常10分為一組）③ 用正字記號統計次數 ④ 填入次數欄

關鍵概念

組距 = 各組的上限 − 下限
組中點 = (上限 + 下限) ÷ 2
包含下限，不含上限（含上限的100分歸入90~100）

次數分配折線圖

以各組的組中點為橫坐標，各組次數為縱坐標，標出各點後依次用線段連接。

重要提醒
  • 分組時各組都「包含下限，不含上限」
  • 100分通常歸入90~100這組
  • 直方圖：以組距為底，次數為高，長條緊密相連
  • 折線圖：用組中點代表各組資料平均
例

成績資料最高100分，最低42分。從40分起，每10分一組：40~50（3人）、50~60（4人）、60~70（5人）、70~80（8人）、80~90（6人）、90~100（4人）。組中點分別為45,55,65,75,85,95。

🗝️ 教學提示

  • 分組時，「40~50 表示成績≥40 且 <50」，避免與不等式「以下」混淆
  • 統計課程中不用「以下」這個名詞，避免和不等式的「以下」衝突
  • 折線圖的組中點只需將各組上限與下限相加除以2即可
  • 可搭配電腦 Excel 實際操作次數分配表的製作

📝 形成性評量

Q1. 七年甲班數學小考成績次數分配表如下：
40~50：3人、50~60：4人、60~70：5人、70~80：8人、80~90：6人、90~100：4人
若及格標準為60分，則不及格的人數有幾人？
✅ 不及格（60分以下）：40~50有3人，50~60有4人，共 3+4 = 7人。
Q2. 成績分組為40~50，其組中點為？
✅ 組中點 = (40+50)÷2 = 45。組中點用來代表該組每位學生的成績估計值。

平均數

▶ 點擊按鈕，加入極端值，觀察平均數如何被影響
⚖️

平均數（算術平均數）

定義

n個數值資料的平均數，是這n個數值資料的總和除以資料個數n。又稱算術平均數。

公式

平均數 = 數值總和 ÷ n

已分組：平均數 ≈ Σ(組中點×次數) ÷ 總次數

合併：平均數 = (甲總和+乙總和) ÷ (甲人數+乙人數)

重要提醒
  • 平均數容易受極端值影響
  • 已分組資料用組中點估算平均數（會有誤差）
  • 不能直接平均兩組的平均數（需加權）
  • 計算機 M+ 鍵可累加乘積
例

年終獎金：5、5、5、6、7、8、8、11、35（萬元）
平均 = (5+5+5+6+7+8+8+11+35)÷9 = 90÷9 = 10萬元
但35太極端，10不代表多數人的實際獎金。

🗝️ 教學提示

  • 說明平均數的意義：代表資料的「集中趨勢」，但易受極端值影響
  • 已分組求平均：以組中點×次數估計各組總分，再除以總人數。結果為估計值
  • 合併平均：不能直接平均兩組的平均數！需各組總分相加後除以總人數
  • 計算機技巧：利用 M+ 鍵累加各組（組中點×次數）的值

📝 形成性評量

Q1. 勇士隊五場得分：113、132、118、116、129。騎士隊五場得分：91、113、113、137、120。哪隊平均得分較高？
✅ 勇士：(113+132+118+116+129)÷5 = 608÷5 = 121.6。騎士：(91+113+113+137+120)÷5 = 574÷5 = 114.8。勇士隊較高。
Q2. 七年乙班29人平均數學成績74分，七年丙班32人平均71分，兩班合併的全體平均數為？（四捨五入至小數點後第1位）
✅ 乙班總分：74×29=2146；丙班總分：71×32=2272；合計：4418÷61≈72.4分。不能直接用(74+71)÷2，因為兩班人數不同！
Q3. 七年甲班30位同學公共服務時數次數分配：0時6人、1時2人、2時7人、3時6人、4時5人、5時0人、6時4人。全班平均公共服務時數為？
✅ 總時數 = 0×6+1×2+2×7+3×6+4×5+5×0+6×4 = 0+2+14+18+20+0+24 = 78。平均 = 78÷30 = 2.6時。

中位數

▶ 點擊切換奇數/偶數筆資料，觀察中位數的位置
🎯

中位數

定義

將n筆數值資料由小到大排列後，取最中間的數來代表這群資料。中位數不易受極端值影響。

公式

n是奇數：中位數 = 第 (n+1)/2 個資料值

n是偶數：中位數 = 第 n/2 個 與 第 n/2+1 個 資料值的平均數

重要提醒
  • 排列前一定要先由小到大排序
  • 偶數筆：取中間兩個數的平均
  • 已分組：從最低組累加次數，找到超過一半的那一組
  • 不宜求連續型（已分組）資料的確切眾數
例

9筆：5,5,5,6,7,8,8,11,35 → 中位數 = 第5個 = 7萬元
10筆（加入10）：5,5,5,6,7,8,8,10,11,35 → 中位數 = (7+8)÷2 = 7.5萬元

🗝️ 教學提示

  • 特地用含極端值（35）的例子，說明中位數為何比平均數更能代表「一般水準」
  • 已分組求中位數位置：30人→找第15和第16個的平均；先累加各組，看哪組跨越第15個
  • 圓形圖求中位數：各扇區累計百分比超過50%時，跨越的那個類別就是中位數

📝 形成性評量

Q1. 牛仔褲設計師隨機問了9位青少年的身高（公分）：163、166、192、171、172、158、169、170、162，這群人身高的中位數為？
✅ 由小到大排列：158、162、163、166、169、170、171、172、192。9筆（奇數），中位數為第(9+1)/2=第5個：169公分。
Q2. 七年甲班30位同學家中人口數次數分配：2口1人、3口4人、4口10人、5口7人、6口5人、7口2人、8口1人。中位數為幾口？
✅ 30人→中位數為第15和第16個的平均。累計：2口1人、3口5人、4口15人。4口以下有15人，5口以下有22人。第15個=4，第16個=5，中位數 = (4+5)÷2 = 4.5口。

眾數

▶ 點擊長條增加次數，觀察眾數的變化（黃色標示眾數）
目前眾數：5萬元（出現2次）
🏆

眾數

定義

一群資料中，出現次數最多的資料（或其類別），稱為這群資料的眾數。

特性

眾數不受極端值影響
可以有一個或多個眾數
類別資料也可求眾數
不宜求已分組連續資料的眾數

三種代表值比較
  • 平均數：最常用，易受極端值影響
  • 中位數：不受極端值影響，代表「中間水準」
  • 眾數：不受極端值影響，最直觀，適合市場調查
例

年終獎金：4、5、5、5、6、6、7、7、20、35（萬元）
眾數 = 5萬元（出現3次最多）
里長選舉：1號1527票、2號1860票、3號253票 → 眾數 = 2號（1860票，得票最多的類別）

🗝️ 教學提示

  • 眾數可應用於類別資料（如服飾尺寸、投票結果），這是平均數和中位數做不到的
  • 眾數可以不只一個（多峰分布）
  • 迷思：里長選舉「眾數」不是得票數1860，而是得票最多的候選人「2號」
  • 加減乘除對三種代表值的影響：全部加k→各加k；全部乘k→各乘k

📝 形成性評量

Q1. 某公司部門年終獎金（萬元）：4、5、5、5、6、6、7、7、20、35。下列敘述何者正確？
✅ 眾數=5萬元（出現3次）。平均數=(4+5+5+5+6+6+7+7+20+35)÷10=100÷10=10萬元，但10萬被20和35拉高，不代表一般員工。眾數5萬更接近多數人的實際水準。
Q2. 孟林老師將全班30位同學的數學成績，先加上原來分數的10%，再加8分（加分後沒人超過100分）。若加分前全班平均60分、中位數50分、眾數45分，則加分後的眾數為？
✅ 每位同學都做相同運算：新分數 = 原分數×1.1+8。眾數45分→新眾數 = 45×1.1+8 = 49.5+8 = 57.5分。

📋 5-1 總結 Cheat Sheet

📊 統計圖表比較

  • 長條圖：類別資料，條有間隔
  • 直方圖：數值資料，條緊相連
  • 折線圖：呈現趨勢變化
  • 圓形圖：呈現比例（%）
  • 列聯表：兩種類別的交叉統計

📋 次數分配

  • 組距 = 上限 − 下限
  • 組中點 = (上限+下限)÷2
  • 包含下限，不含上限
  • 100分歸入90~100組
  • 折線圖以組中點為橫坐標

⚖️ 平均數

平均數 = 總和 ÷ n

  • 已分組：Σ(組中點×次數)÷n
  • 合併：(甲總分+乙總分)÷(甲n+乙n)
  • ⚠️ 易受極端值影響

🎯 中位數

先由小到大排列

  • n奇數：第(n+1)/2個
  • n偶數：第n/2與n/2+1個的平均
  • 已分組：累加找跨越n/2的那組
  • ✅ 不受極端值影響

🏆 眾數

出現次數最多的資料

  • 可以有多個眾數
  • 類別資料也能用
  • ✅ 不受極端值影響
  • 常用於市場調查

🔄 加減乘除的影響

  • 全部+k → 平均/中位/眾數各+k
  • 全部×k → 平均/中位/眾數各×k
  • 新值 = a×原值+b → 代入計算
